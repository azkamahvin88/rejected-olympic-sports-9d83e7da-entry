A deterministic Python program that writes one one-line rejected Olympic sport — Competitive Procrastination: athletes have four years to train; nobody starts until the night before — to `/output/entry.txt` for make.fun's "Rejected Olympic Sports" bounty.

## Run it

```sh
python3 main.py
```

## How it works

`main.py` (Python standard library only, no network, no randomness) holds one fixed joke string and writes it to `/output/entry.txt`. Two runs produce byte-identical output. See [STUDY.md](STUDY.md) for how the joke was chosen from 26 candidates scored against the judge's brief.
